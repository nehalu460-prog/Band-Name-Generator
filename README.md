# 🐍 100 Days of Code – Python Bootcamp Projects

This repository documents my progress through the **100 Days of Code: The Complete Python Pro Bootcamp** by **Dr. Angela Yu**.

The goal of this repository is to track my learning journey, strengthen my Python programming skills, and build a solid foundation in software development through consistent practice and hands-on projects.

## 📚 About the Challenge

The **100 Days of Code** challenge is a project-based learning journey designed to teach Python from beginner to advanced levels. Each day focuses on building practical skills through coding exercises, mini-projects, and real-world applications.

Throughout this challenge, I will be exploring:

* Python Fundamentals
* Object-Oriented Programming (OOP)
* Data Structures & Algorithms
* File Handling
* APIs and Web Requests
* Automation with Python
* Web Scraping
* GUI Development
* Data Analysis
* Flask Web Development
* Software Development Best Practices
